# AI-SMC 用户操作手册

> 面向日常使用者：这份手册不讲部署，不讲代码，重点讲如何更好地使用 AI-SMC 盯盘、理解信号、控制风险和复盘结果。

---

## 1. 系统一句话说明

AI-SMC 是一个围绕 **黄金 XAUUSD** 和 **比特币 BTCUSD** 的自动化交易辅助系统。它用 SMC 聪明钱结构寻找交易区域，用 M15 周期确认入场，用 AI 或本地规则判断市场环境，再通过 MT5/EA 执行或记录交易意图。

你日常不需要理解所有代码，只需要看懂三件事：

1. 现在有没有持仓。
2. 系统为什么开仓或不开仓。
3. 今天风险是否还允许继续交易。

---

## 2. 日常使用主流程

### 开盘前 3 分钟

1. 打开 Web 盯盘台：`http://localhost:8765`
2. 看右上角状态灯：
   - **运行中**：系统正在正常读取数据。
   - **数据陈旧**：系统可能没有拿到最新行情，需要继续观察。
   - **已断线**：优先检查 VPS、MT5、启动窗口或服务。
   - **已暂停**：系统不会开新仓。
3. 看“系统健康”：
   - MT5 连接正常。
   - 数据新鲜度在可接受范围内。
   - 下次检查倒计时正常跳动。
4. 看“风控闸门”：
   - 显示“允许开仓”才说明风控层没有阻挡。
   - 如果显示“已阻断开仓”，不要手动追单。

### 盘中盯盘

建议按这个顺序看页面：

1. **持仓状态**：空仓、多单、空单。
2. **今日盈亏**：实时浮盈或今日交易次数。
3. **今日概览**：今日已实现盈亏、开单数量、风控阻挡次数。
4. **为什么不开仓**：空仓时最重要，看系统正在等什么。
5. **价格在区间哪里**：判断当前价格是否接近多单区、空单区或中段观望。
6. **SMC 订单流雷达**：先快速判断交易条件，再展开学习每一层 SMC 逻辑。
7. **AI 最新市场环境判断**：只作为过滤和背景判断，不当作单独开仓信号。

### 收盘或睡前

1. 看“今日交易”表有没有异常开单。
2. 看“今日分组盈亏”，区分主策略和试验策略表现。
3. 如果有连续亏损或风控触发，保持系统暂停或降低参数，不要急着恢复激进设置。
4. 记录当天最重要的 1-2 个现象：例如“AI 中性但 SMC 多次给信号”“亚盘配额用完”“价格一直在区间中段”。

## 3. 盯盘台每个区域怎么读

### 顶部状态灯

顶部状态灯是第一优先级。

| 状态 | 含义 | 建议动作 |
|---|---|---|
| 运行中 | 系统正常工作 | 可以继续观察 |
| 数据陈旧 | 状态文件长时间没更新 | 等 1 个周期；仍不恢复就检查 VPS/MT5 |
| 已暂停 | 人工暂停开新仓 | 已有仓位仍需单独管理 |
| 已断线 | 盯盘台无法读取运行状态 | 先排查服务，不要根据旧数据交易 |

### 持仓状态

这里优先显示 MT5 实时持仓。

- **空仓中**：系统没有检测到当前持仓。
- **多单 X 手 @ 价格**：当前持有买入方向。
- **空单 X 手 @ 价格**：当前持有卖出方向。
- 下面的订单号用于和 MT5 持仓核对。

如果 MT5 里有仓位但页面显示空仓，先刷新页面，再看 `MT5 连接` 和 `数据新鲜度`。不要用旧页面判断实际仓位。

### 今日盈亏

有持仓时，显示实时浮动盈亏。

无持仓时，通常显示今日开仓次数或暂无交易。这个区域不是最终账单，最终盈亏应以 MT5 成交历史和系统对账为准。

### 实时持仓与移动止损

这里会显示每笔持仓所属策略分组、方向、手数、开仓价和移动止损预设。

- **黄金主策略**：黄金主线策略。
- **黄金试验策略**：黄金实验分组，用于对比验证。
- **比特币主策略**：BTCUSD 主线策略。
- **移动止损 X R @ Y R**：达到 X 倍风险收益后，移动止损距离按 Y 倍风险处理。

移动止损不是让你手动改止损的命令，而是帮助你理解系统对当前环境的持仓管理倾向。

### 今日分组盈亏

这里用来回答“到底是哪一组策略今天表现好或差”。

- **已实现盈亏**：已经平仓的盈亏。
- **浮动盈亏**：当前还没平仓的浮动结果。
- **笔数**：今日已平仓或记录到的交易数量。

如果主策略稳定，试验策略波动很大，应优先信任主策略，不要因为试验策略单日表现好就扩大风险。

### AI 最新市场环境判断

AI 市场环境只用于辅助理解：

| 环境 | 人话解释 | 使用方式 |
|---|---|---|
| 上涨趋势 | 大周期偏多 | 多头信号更值得关注 |
| 下跌趋势 | 大周期偏空 | 空头信号更值得关注 |
| 震荡整理 | 区间为主 | 更关注上下边界，不追中段 |
| 方向切换 | 可能从震荡转趋势或相反 | 降低主动干预，等待确认 |
| 历史高位突破 | 价格处在强突破背景 | 谨慎做反转，避免摸顶 |

重要原则：**AI 不是开仓按钮**。系统最终仍要经过 SMC 结构、M15 入场、风险回报比和风控闸门。

### 为什么不开仓

这是空仓时最有用的区域。常见提示：

- **价格在区间中段**：没有足够好的风险回报，不追单。
- **价格到了支撑位，但 M15 还没出现反转信号**：位置到了，但确认不够。
- **风险回报比不够**：不是没有机会，而是这笔不划算。
- **区间太窄**：空间不够，容易被噪音扫损。
- **找不到可交易区间**：当前市场结构不适合该模式。

看到“不开仓”通常是好事。系统的价值不只是开单，也包括过滤不值得做的单。

### 价格在区间哪里

区间条把价格位置分成三块：

- **靠下：多单区**，系统更可能等待买入确认。
- **中段：观望区**，风险回报通常不好。
- **靠上：空单区**，系统更可能等待卖出确认。

不要在中段手动追单。中段开仓最容易出现“止损远、止盈近”的问题。

### SMC 订单流雷达

这个区域用于把订单流判断拆成可读的结构，帮助你先判断当前是否接近可交易条件，再学习每一层 SMC 逻辑。雷达是系统对订单流的结构化分析，不是手动追单信号；只有入场、风险和风控通过后，才形成可交易候选。

雷达通常分成五层：

1. **结构**：D1/H4 偏多、偏空，还是方向不清晰。方向不清晰时，不要只因为短周期波动就手动追单。
2. **交易区**：H1 是否有可用订单块或 FVG。没有明确交易区时，价格再快也通常只是观察对象。
3. **流动性**：上方或下方是否有等高、等低，或已经出现扫流动性的迹象。它用于判断价格可能先去哪里拿流动性。
4. **入场**：M15 是否出现 CHoCH、BOS、FVG 回补等触发。位置到了但没有入场触发，仍然不是完整 setup。
5. **风险**：候选 setup 是否满足 RR、共振和风控要求。风险层不过，就算方向看对也不应视为可交易候选。

推荐阅读顺序：

1. 先看顶部一句话结论，快速知道系统当前偏向、等待什么或为什么不做。
2. 再看红黄绿模块，判断结构、交易区、流动性、入场和风险分别处在通过、等待还是阻断状态。
3. 再展开“学习每一层 SMC 判断”，理解系统如何从 D1/H4 结构走到 H1 交易区和 M15 入场触发。
4. 最后展开“关键价位地图”，核对订单块、FVG、等高等低、扫流动性位置和当前价格的关系。

学习 SMC 时，不要只看最终买卖。更值得看的是系统在哪一层被阻断，以及阻断原因是否合理。如果旧数据源还没有写入 `smc_orderflow`，页面会回落显示 `SMC 阶段追踪`。

## 4. 设置页怎么用

### 紧急开关

紧急开关只控制“是否允许新开仓”。

- 点击**暂停交易**：系统停止开新仓。
- 点击**恢复交易**：下一个 15 分钟检查周期恢复按策略开仓。
- 已经开的仓不会自动平掉，需要在 MT5 手动处理或等待止损/止盈。

适合暂停的情况：

- VPS 或 MT5 状态不稳定。
- 连续亏损后想冷静观察。
- 重大新闻前后不想让系统自动开新仓。
- 你要手动维护 MT5 或 EA。

### 边界触发宽度

这个参数决定价格离区间上下边界多近才算“到了位置”。

- 数字越大：更容易开单，但信号更宽松。
- 数字越小：更严格，交易更少。

建议：

- 系统刚稳定运行时，不要调太大。
- 如果近期假突破多、扫损多，优先调小。
- 如果长时间不开单，可以小幅调大，但每次只调 5% 左右。

### 最低风险回报比

这个参数决定至少要有多少潜在收益才值得承担 1 份风险。

- 1.2:1：比较实用，交易机会较多。
- 1.5:1 以上：更保守，机会明显减少。
- 低于 1.2:1：不建议，容易做“赚小亏大”的单。

建议长期保持在 1.2 到 1.5 之间。

### 亚盘每日最多开仓

亚盘波动较弱，容易横盘反复扫损。这个参数限制亚盘开仓次数。

- 0：完全禁止亚盘开仓。
- 1-2：较稳妥。
- 3 以上：偏激进。

如果你发现亏损主要集中在北京时间 8:00-16:00，优先把亚盘配额降到 0 或 1。

### 时段开关

可以分别控制亚盘、伦敦盘、纽约盘是否允许开新仓。

一般建议：

- 新系统观察期：亚盘保守，伦敦和纽约正常。
- 重大新闻日：必要时关闭纽约盘。
- 网络或 VPS 不稳定：全部暂停。

### AI 中性时暂停

开启后，AI 判断不清方向时系统更倾向于不开单。

建议默认开启。只有当你明确想收集更多样本，才考虑短期关闭。

## 5. 风控规则怎么理解

AI-SMC 的核心原则不是“多开单”，而是“只做满足结构和风控的单”。

### 单笔风险

系统会根据账户余额、止损距离和最大手数限制计算仓位。不要因为某次信号看起来很强，就手动放大手数。

### 连亏止损

连续亏损达到阈值后，系统会触发每日保护。触发后应尊重停盘状态，不要马上手动恢复。

### 回撤保护

当日亏损或总回撤达到限制，系统应停止新开仓。这个机制是为了防止策略在异常行情里连续试错。

### 亚盘配额

亚盘配额是专门限制低波动时段过度交易。它不是系统故障，而是交易纪律。

## 6. 什么时候人工干预

### 可以人工暂停

- 系统状态灯红色或长时间黄色。
- MT5 无法连接或 EA 状态异常。
- 重大经济数据、央行讲话、非农、CPI 等高冲击事件前。
- 连续亏损后你需要复盘。
- VPS 重启、网络波动、更新软件时。

### 不建议人工干预

- 只是因为系统空仓太久。
- 只是因为价格快速上涨或下跌。
- 只是因为 AI 看多或看空。
- 只是因为刚错过一笔盈利交易。

如果你选择手动交易，应把手动仓位与系统仓位分清，避免系统和人工互相干扰。

## 7. 每日复盘模板

建议每天只复盘 10 分钟，重点看事实，不要过度解释单笔盈亏。

```text
日期：
交易品种：
系统状态：运行中 / 暂停 / 数据陈旧 / 异常
今日开单数：
今日已实现盈亏：
当前浮动盈亏：
主策略表现：
试验策略表现：
风控是否触发：
主要不开仓原因：
最值得学习的一条 SMC 判断：
明天是否需要调整参数：
```

参数调整建议写清楚原因，例如：

- “亚盘连续 2 天亏损，明天亚盘配额从 2 降到 1。”
- “中段追踪信号太多但不开单正常，不调整。”
- “AI 多次中性，保持 AI 中性暂停开启。”

## 8. 每周复盘重点

每周不要只看净利润，还要看交易质量：

1. 总交易数是否足够，是否过少导致结论不可靠。
2. 盈亏来自主策略还是试验策略。
3. 亏损是否集中在某个时段。
4. 亏损是否集中在震荡、突破或方向切换环境。
5. 风控阻挡是否过多，是否说明参数太严格。
6. AI 判断和最终交易方向是否经常冲突。

少量交易的胜率没有太大意义。更重要的是持续观察 1-3 个月后的稳定性。

## 9. 用户纪律

请把系统当作“严格执行规则的交易助手”，不是稳赚工具。

必须遵守：

1. 不因单日亏损马上大改参数。
2. 不因单日盈利马上加大手数。
3. 不在状态灯异常时按旧信号交易。
4. 不在系统暂停后手动补单追单。
5. 不把 AI 判断当成单独买卖建议。
6. 不忽略 MT5 真实持仓，以 dashboard 旧数据替代账户事实。

更稳的使用方式是：让系统跑、让数据积累、每周小步复盘，参数一次只改一个。

## 10. 项目复盘总结

AI-SMC 的主要价值不是某个单一指标，而是形成了完整闭环：

- **策略层**：SMC 结构、多时段方向、M15 入场、区间与趋势模式。
- **AI 层**：市场环境判断、方向过滤、算力可关闭和降级。
- **执行层**：MT5/EA 执行、订单号、分组策略、对账。
- **风控层**：单笔风险、连亏停盘、回撤保护、亚盘配额。
- **监控层**：Web 盯盘台、实时持仓、今日概览、原因解释、SMC 订单流雷达。
- **复盘层**：交易日志、分组盈亏、AI 判断记录、每日摘要。

它最适合的使用方式是：在模拟或小资金阶段长期观察，用 dashboard 理解系统为什么做或不做，再根据周级样本逐步调整。不要把它当成短期暴利工具，也不要因为几笔交易就判断策略成败。

## 11. 快速排错

| 现象 | 优先检查 | 建议动作 |
|---|---|---|
| 页面打不开 | dashboard 服务是否启动 | 重新启动 `start_dashboard_web.bat` |
| 页面红灯已断线 | 状态文件是否更新 | 检查 VPS、MT5、live 进程 |
| 页面黄灯数据陈旧 | 是否刚好市场休市或进程卡住 | 等一轮；仍异常就重启服务 |
| MT5 有仓位但页面空仓 | `/api/positions` 数据是否更新 | 刷新页面，核对 MT5，必要时重启 dashboard |
| 设置保存后没变化 | 是否等到下一轮检查 | 等 15 分钟内的下一个周期 |
| 紧急暂停后仓位还在 | 暂停只阻止新仓 | 在 MT5 手动处理已有仓位 |
